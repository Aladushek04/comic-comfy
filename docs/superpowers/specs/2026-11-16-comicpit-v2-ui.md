# ComicPit-V2: интерфейс

Дата: 2026-11-16. Часть проекта `2026-11-16-comicpit-v2-design.md`.
Основание: аудит веб-слоя (разделы 3.3 и 5) и проверка документации NiceGUI 4.

## 1. Состояния

Состояние задания — отдельная ось от состояния среды и формы. «Нет ComfyUI» не состояние
задания, а модификатор доступности кнопок.

| state | центр | главное действие |
|---|---|---|
| `empty` | пунктирная рамка «Перетащи фото», три шага, ожидание по времени | dropzone |
| `ready` | фото крупно, свёрнутый «что уйдёт» (positive/negative из PromptBuilder) | Старт |
| `queued` | «Ждёт исполнителя · позиция 2», таймлайн в `pending` | Отмена (снимает из очереди) |
| `running` | 4–5 фаз + шаг текущего прохода | Отмена (`/interrupt`) |
| `described` | описание готово, кадра нет; бейдж происхождения (VLM / кэш / ручное / теги) | Сгенерировать по описанию |
| `done` | кадр, полоса миниатюр, параметры, «Скачать» | Скачать |
| `partial` | баннер «кадров 2, из них 1 с ошибкой» над полосой, кадры не скрываются | Скачать / Повторить |
| `failed` | `error-zone` с полным текстом, журнал в диалоге | Повторить |
| `expired` | «История задания истекла», путь `out\<фото>_<хэш>\` | История кадров |
| `blocked` | годных сборок нет: панель с командой пересборки и проблемами | — |

Среда: `comfy.ok` / `launchable` (поднимется сам) / `lm.ok` / связь / тема. Разделение
«Старт» и «Только описание» обязательно: описание работает без ComfyUI, генерация — нет.

## 2. Раскладка

```
topbar  sticky 56px   [связь][ComfyUI][Описание][очередь]        [тема]
rail 400–420   PhotoSlot / StylePicker / RunControls / StartAction
stage          PhaseTimeline ▸ StepBar / FrameStage / FrameStrip / ErrorZone
               ▸ вкладки «Кадр / Параметры / Промпт / История»
```

- **1280:** две колонки, rail `lg:sticky lg:top-16`; инспектора нет — «Параметры /
  Промпт / История» живут вкладками под кадром на любой ширине.
- **1600–1920:** те же две колонки, `max-w-[1800px]`, rail 420, кадр ограничен высотой
  `min(62vh,720px)`. Отдельной третьей колонки-инспектора **нет**: она дублировала бы
  те же панели и заводила второй путь отрисовки.
- **Телефон не поддерживается.** Сервис работает только на ПК; минимальная ширина — 1280.
  Ниже 1280 страница не перестраивается, а показывает строку «нужен экран от 1280 px».
  Нижней панели, drawer на телефоне и одноколоночной раскладки в V2 нет.

Точные значения, чтобы реализация не «поехала»: topbar 56 px; rail 400 px до 1600 и 420 px
после; гаттер 16 px, внутри карточки 16; кадр `height: min(62vh, 720px)`; полоса
миниатюр 56 px; вкладки 32 px.

Рельс подобран по высоте окна 900 px, чтобы «Старт» был виден без прокрутки и ничего не
перекрывал: фото 160 px, строка стиля 32 px, «Параметры запуска» — две строки по 32 px,
кнопки запуска в одну строку. Липнет сам рельс (`position: sticky; top: 16 px` под
верхней панелью), а не блок запуска: липкий блок висел бы поверх карточек. Ниже 900 px
высоты рельс не липнет и прокручивается со страницей — иначе «Старт» уехал бы под
нижний край.

## 4. Визуальный язык

Один акцент — фиолетовый `#7c3aed` (заливка), `#a78bfa` в тёмной теме для текста.
Красный и оранжевый заняты ошибкой и предупреждением, синий — дефолт NiceGUI, от которого уходим.

- Токены в `:root` и `body.body--dark`: `--bg --surface --surface-2 --ink --ink-2 --line
  --accent --accent-fill --accent-on --ok --warn --err`.
- `ui.colors(primary='#7c3aed', …)` — тогда кнопки и прогресс наследуют акцент пропсами.
- Тип-шкала: 0.75 / 0.875 / 1 / 1.25 / 1.5 rem. Числа — `font-mono tabular-nums`.
- Отступы: 4/8/12/16/24/32. Радиусы: `rounded-lg` карточки, `rounded` инпуты, `rounded-full` бейджи.
- ~10 классов в `@layer components` (`cp-card`, `cp-title`, `cp-meta`, `cp-num`, …) вместо
  108 литеральных строк `.classes(...)`.
- Тёмная тема без вспышки: `@ui.page('/', dark=read_theme())` + `ui.dark_mode`.

## 5. Транспорт

Три слоя, EventSource основным каналом не используется: в документации NiceGUI SSE нет,
и он завёл бы второй путь отрисовки (парсить JSON в `run_javascript` и мутировать DOM).

1. **Push по открытому сокету:** `nicegui.Event` — задание публикует патч, страница
   подписана в своём scope; подписка снимается в `app.on_disconnect`/`on_delete`.
2. **Полный снапшот** на `app.on_connect` (в том числе при переподключении) и при рассинхроне.
3. **Сторожевой таймер** `ui.timer(2.0, active=(status in ("queued","running")))` — если
   push не приходил >3 с, берём `snapshot()`.

Правила: патч несёт абсолютные значения; `rev` монотонен, разрыв → `resync` + снапшот;
шаги коалесцируются до 4 Гц; секунды считаются на клиенте от `started_at`/`server_now`;
кадры только добавляются.

Мерцание и сброс выбранной миниатюры лечатся структурой: `FrameStrip` хранит
`key → элемент` и никогда не вызывает `clear()`; выделение — `selected_key` в
`app.storage.tab`; автовыбор последнего `refined` только при `user_selected == False`;
большое изображение — два `<img>` с кроссфейдом.

## 6. Визуальный контракт

Утверждённый макет — эталон. Чтобы реализация не «поехала», фиксируем не картинку, а числа
и запреты; проверяются они в T2 и в ревью, а не на глаз.

**Не меняется без отдельного решения:**

1. Токены и их значения (раздел 4): `--bg --surface --surface-2 --ink --ink-2 --line
   --accent --accent-fill --accent-on --ok --warn --err` для обеих тем.
2. Один акцент — `#7c3aed` / `#a78bfa`. Красный, оранжевый и дефолтный синий NiceGUI
   в интерфейсе не появляются.
3. Пять ступеней типа (0.75 / 0.875 / 1 / 1.25 / 1.5 rem) и шесть отступов (4/8/12/16/24/32).
4. Порядок регионов: topbar → rail (фото, стиль, параметры запуска, Старт) → stage
   (фазы, вкладки, содержимое). Третьей колонки-инспектора нет: панели живут вкладками.
5. Стили — списком с весом LoRA справа, не выпадающим списком и не чипами.
6. Вкладки «Кадр / Параметры / Промпт / История» переключают содержимое; «История» читает
   `run.json`, а не память страницы.

**Запрещено в коде:**

- литеральные строки `.classes(...)` и `.style(...)` в компонентах — только классы
  `cp-*` из `@layer components`;
- цвета и размеры, взятые не из токенов;
- второй путь отрисовки (EventSource + `run_javascript`, `clear()` + пересборка).

**Проверки T2 (Chromium), по одной на пункт:**

- обе темы: фон, поверхность и текст берутся из токенов, ни одного литерального цвета
  в вычисленных стилях ключевых блоков;
- вкладки переключают панели, состояние переживает перезагрузку вкладки браузера;
- стиль выбирается списком, выбранный пункт виден, вес LoRA отображается;
- Старт липкий и остаётся в поле зрения при прокрутке кадра;
- при ширине 1279 страница показывает требование 1280, а не ломается.
