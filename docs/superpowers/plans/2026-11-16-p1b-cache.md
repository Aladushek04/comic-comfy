# P1b: кэш описаний

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** кэш описаний получает версию схемы и миграцию, а `photo_prompt` перестаёт знать о его ключах.

**Architecture:** `comic/cache.py` владеет форматом: `CacheRecord` (dataclass), чтение с миграцией, атомарная запись. Старые функции `photo_prompt.cache_path/read_cache/write_cache/scene_slug/fingerprint` остаются как обёртки, чтобы 312 проверок и весь вызывающий код не менялись.

**Tech Stack:** Python 3.13, stdlib, `hashlib`, существующий `write_json` (tmp → fsync → replace).

**Spec:** `docs/superpowers/specs/2026-11-16-comicpit-v2-design.md`, 7.2 (кэш) и 7.7.

## Global Constraints

- `fingerprint()` остаётся 12 символов sha1 и не меняет формулу: иначе осиротеет вся история `out\<фото>_<хэш>\`.
- Ключи старого кэша читаются без потерь; запись без `scene_applied` по-прежнему не отдаётся как сценическая.
- Запись только атомарная (tmp → fsync → `os.replace`), как сейчас.
- Никаких новых зависимостей, никаких изменений в промптах и графах.
- Оба набора зелёные, `check_install` — код 0.

## Review Focus

- Старый кэш без поля `schema` не должен считаться новым и наоборот.
- `scene` сравнивается по значению, а не по slug: «на пляже» и «в горах» не делят запись.
- `addons`/`addon_tags`/`addon_replaced`/`addon_size` переживают миграцию (иначе `--no-tags` перестанет возвращать описание).
- Поле `raw` сейчас пишется и не читается — при миграции не потерять, но и не начать читать.
