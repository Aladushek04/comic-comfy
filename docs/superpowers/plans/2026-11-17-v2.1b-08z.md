`image_z_image_turbo_fun_union_controlnet.json` добавляет контроль:


объявлен как `model, model_patch, vae, image, strength` + необязательные `mask`,
`start_percent`, `end_percent`.

## Решения, которые принимаются здесь (не по вкусу, а по устройству базы)

1. **Негатива на этой базе нет.** CFG 1 — сэмплер не читает negative. Поэтому в графе
   остаётся `CLIPTextEncode` с негативом (иначе `meta`, форма и `--recheck` теряют опору),
   но `meta` получает ключ `negative_effective: false`, CLI печатает это одной строкой,
   а `--recheck` на такой сборке отказывается: дописывать промахи в негатив, который не
   читается, — обман. Возрастная рамка держится позитивом (`with_adult`) и описанием VLM.
2. **Это text→image с контролем глубины, а не img2img.** Латент пустой
   (`EmptySD3LatentImage`), геометрию задаёт Fun ControlNet по карте DA3. Второго прохода
   (refine) нет: 8 шагов — весь бюджет базы.
3. **Размер по ориентации фото.** `EmptySD3LatentImage` — 832×1216 для вертикального,
   1216×832 для горизонтального. Ориентация уже вычисляется в `photo_prompt.py` для 01;
   здесь тот же механизм должен патчить узел 12, иначе кадр выйдет квадратным (грабли 0).
4. **Промпт — фраза, а не теги.** Текст-энкодер Qwen3-4B обучен на естественном языке:
   стилевой шаблон пишется предложением, субъект VLM встаёт на место `sample` как и в 07.
5. **LoRA:** `GTAV_ZImageTurbo` (стиль, вес 0.85 — как у `GTAV_IL_MIX`), `NSFW_master_ZIT`
   слотом с весом 0 (поднимать вручную по кадру).
