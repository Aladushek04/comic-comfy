# P6a: чистка кода и панели

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** исчезает второй конвейер `run_batch`, мёртвые флаги и ветки, графы мёртвого редактора; копия для панели ComfyUI перестаёт расходиться с репозиторием.

**Architecture:** `--batch` переезжает на `jobs.run_job` (два прохода: все описания → выгрузка VLM → генерация). `tools/run_batch` удаляется целиком. Синхронизация панели — отдельный скрипт, а не ручное копирование.

**Spec:** `docs/2026-11-16-comicpit-v2-audit.md`, разделы 2.1–2.3.

## Global Constraints

- `--batch` сохраняет поведение: описания пачки при одной загрузке модели, затем выгрузка, затем генерация; провал одного файла не отменяет остальные.
- Флаги, которые раньше молча игнорировались в пачке (`--recheck`, `--save-preset`, `--preset`, `--overrides`), теперь работают или отвергаются с внятной ошибкой.
- Промпты, графы и модели не меняются.
- Наборы зелёные (511+ / 327+), `check_install` — 0.

## Review Focus

- Пачка не должна потерять «без описания: N» и код возврата 1 при провале.
- Удаление `run_batch` не должно осиротеть ни одну проверку: те, что его гоняли, переезжают на `--batch` через `run_job`.
- Копия панели синхронизируется только в одну сторону (репозиторий → панель), без обратной записи.
