# V2.1a: Depth Anything 3 вместо DA2

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** сборки `07_photo_*` и `08_photo_gta` берут глубину из Depth Anything 3 (нативные узлы ComfyUI), а не из `DepthAnythingV2Preprocessor` кастомного пакета.

**Architecture:** В `comic/builds.py` рецепт `photo()` получает три узла вместо одного: `LoadDA3Model` → `DA3Inference` → `DA3Render`, и `ControlNetApplyAdvanced.image` смотрит на рендер. `meta` и тексты промптов не меняются.

**Spec:** `docs/superpowers/specs/2026-11-17-comicpit-v2.1-design.md`, фаза V2.1a.

## Global Constraints

- `meta` всех сборок равна `tools/golden/meta.json`; промпты равны `tools/golden/prompts.json`.
- Меняются только графы `07_photo_*` и `08_photo_gta`; остальные восемь — байт в байт.
- Веса: `geometry_estimation\depth_anything_3_mono_large.safetensors` (1.34 ГБ, уже скачан).
- `normalization="v2_style"` — та же нормализация, что даёт DA2 в controlnet_aux; иначе
  полярность глубины перевернётся и ControlNet получит изнанку.
- `apply_sky_clip=false`: включать только если по кадру видно, что небо портит глубину.
- Никакой генерации без разрешения владельца; `check_widgets.py` поднимает ComfyUI сам.

## Review Focus

- `geometry_estimation` нет ни в `extra_model_paths.yaml`, ни в образце — без этого узел
  не увидит файл и сборка упадёт на «value not in list».
- DynamicCombo в API-формате — это объект (`{"mode": "mono"}`, `{"output": "depth", ...}`),
  а не строка; проверяется `check_widgets.py`.
- Id новых узлов не должны совпасть с id LoRA рук (20) и сэмплера (13).
- Время кадра не должно вырасти больше чем на пару секунд: DA3 large на 16 ГБ считается
  на GPU, но перед сэмплером.
