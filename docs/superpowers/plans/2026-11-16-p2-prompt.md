# P2: один путь сборки промпта

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** `PromptBuilder` — единственное место, где собираются positive и negative; CLI, предпросмотр и веб дают побайтно одно и то же.

**Architecture:** `comic/prompt.py` получает `build(subject, negative_extra, meta, fields, landscape, image_name) -> (positive, negative, applied)`. Старые `compose_positive`, `compose_negative`, `join_tags` становятся обёртками. Эталон — `positive`/`negative` из `out\v2-baseline\run.json` (10 кадров, 527 и 367 символов).

**Tech Stack:** Python 3.13, stdlib.

**Spec:** `docs/superpowers/specs/2026-11-16-comicpit-v2-design.md`, 7.2 (PromptBuilder), 7.7 (байтовое равенство и разрешённый фикс).

## Global Constraints

- До Task 2 промпты обязаны совпадать с baseline **побайтно** для всех пяти сборок.
- Разрешённое расхождение ровно одно: убрать `theofficialpit style` из `07_comic`, `07_jp`, `07_bimbo` (и `01_scene_comic`/`01_scene_jp`). Ничего другого в промптах не меняется.
- Порядок тегов, `NEG_GUARD` последним и `with_adult` не трогаются.
- Никаких изменений в графах, кроме этих трёх шаблонов.
- Наборы зелёные (340+ / 192+), `check_install` — 0.

## Review Focus

- `landscape` и имя файла входят в аргументы: иначе предпросмотр снова разойдётся с кадром.
- `applied` (что реально применено) не путается с `positive`: `--style-weight` и переопределения пишутся в `applied`.
- Стиль берётся из `meta.positive_template`; при его отсутствии — отказ, а не тихий `STYLE_PREFIX` (аудит, риск 3).
- Переопределения `positive_override`/`negative_override` проходят через `guard` (рамка не снимается).
