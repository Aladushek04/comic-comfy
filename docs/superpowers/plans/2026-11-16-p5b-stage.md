# P5b: сцена, вкладки и правки рельса

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** на `/v2` появляется сцена: фазы, шаг текущего прохода, вкладки «Кадр / Параметры / Промпт / История», полоса кадров и зона ошибки; рельс перестаёт прокручиваться внутри себя.

**Architecture:** Новые компоненты в `webapp/components/`: `phase_timeline.py`, `stage_tabs.py`, `frame_stage.py`, `frame_strip.py`, `params_panel.py`, `prompt_panel.py`, `history_panel.py`, `error_zone.py`. Данные — только из `service.snapshot()` и `comic.run`; ничего не пересчитывается на странице.

**Spec:** `docs/superpowers/specs/2026-11-16-comicpit-v2-ui.md`, разделы 1, 3, 6.

## Global Constraints

- Старая страница на `/` не меняется, её 35 проверок зелёные.
- Только ПК, минимум 1280.
- Никаких литеральных `.classes(...)`/`.style(...)`: только `cp-*` и токены.
- Шаги — только по узлам из `meta.samplers` (0.14 №4); подпись прохода — из `passes`.
- Промпт кадра — фактический, из записи кадра, а не собранный заново (0.14 №10).
- Полоса кадров не вызывает `clear()` и хранит выделение по имени файла (анти-мерцание).

## Review Focus

- Вложенный скролл в рельсе исчезает: прокручивается страница, «Старт» липнет вместе
  с рельсом, а не поверх карточек (правка после живой страницы: блок запуска перекрывал
  «Параметры запуска»).
- Бейджи: нейтральная пилюля, цвет только у точки.
- «История» читает `run.json` через `comic.run`, а не память страницы.
- Ошибка показывается в одном месте и одним лимитом.

**Отложено, а не забыто:** «Отмена» задания. Ей нужен `POST /interrupt` в
`webapp/service.py` (сервис сейчас умеет только ставить задание), поэтому кнопка
появится в P5c вместе с расширенной панелью — в `components/start_action.py` это
записано в докстринге.
