# P5a: новый интерфейс рядом со старым

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** новый интерфейс собирается по спецификации и живёт на `/v2`, старый остаётся на `/` и продолжает проходить свои 35 браузерных проверок.

**Architecture:** Вытеснение внутри UI: `webapp/theme.py` (токены), `webapp/labels.py`, `webapp/collect.py` (чистая сборка `JobRequest`), `webapp/components/*` — по одному модулю на компонент, `webapp/v2.py` — страница. Пакет остаётся `webapp/`; переименование в `web/` — P6, чтобы не трогать импорты в 210 проверках.

**Tech Stack:** NiceGUI 4.0.0, Tailwind (CDN), Python 3.14 (.venv-web).

**Spec:** `docs/superpowers/specs/2026-11-16-comicpit-v2-ui.md` (экраны, раскладка, компоненты, токены, транспорт, визуальный контракт).

## Global Constraints

- Старая страница на `/` не меняется: её 35 проверок обязаны остаться зелёными.
- Новый интерфейс — только ПК, минимум 1280; ниже — строка «нужен экран от 1280 px».
- Никаких литеральных `.classes(...)`/`.style(...)` в компонентах: только `cp-*` из `@layer components` и токены.
- Один акцент `#7c3aed` / `#a78bfa`; красный, оранжевый и дефолтный синий NiceGUI не используются.
- Стили — списком с весом LoRA справа. Вкладки «Кадр / Параметры / Промпт / История» переключают содержимое.
- Опрос 600 мс в новом интерфейсе не используется.

## Review Focus

- `collect_form` — чистая функция: без NiceGUI, проверяется в T0.
- Тема применяется в первом HTML (`@ui.page(dark=...)`), без вспышки; переключение пишет `out\theme.json`.
- Новый интерфейс читает тот же `service.snapshot()` и те же `/api/job`, `/media/*`.
- Ни одна из десяти грабель `AGENTS.md` 0.14 не теряется: каждая либо реализована, либо явно отложена с пометкой.
